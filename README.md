# ralph 


`ralph` is a Go CLI that runs a task loop with `.ralph/config.yml` as the source of truth.  
Use `ralph init` to scaffold files, then `ralph run` to repeatedly execute the 3 phases: `pre -> main -> post`.

[[日本語版]](README.ja.md)

## Key behavior

- Reads `.ralph/config.yml` and builds the runner.
- Requires `branchName` in `.ralph/prd.json`; at `run` startup, it does `git switch` to that branch (creates it if missing).
- In the `main` phase, executes `agent.command` via `sh -c` and passes `.ralph/prompt.md` to stdin.
- In the `post` phase, `uses: auto_commit` can commit changes automatically.
- Completion conditions:
  - All `.ralph/prd.json` `stories[].passes` are `true`.
  - A line exactly matching `completion.signal` exists within the last `completion.tail_lines` lines of agent output.

## Prerequisites

- Go (`go.mod`: `go 1.25.0`)
- `git`
- `sh` (POSIX shell)
- Agent CLI configured in `agent.command` (for example: `claude`, `codex`)

## Installation

```bash
go install github.com/shuymn/ralph@latest
```

After installation, make sure your Go bin directory (`$GOBIN` or `$(go env GOPATH)/bin`) is on `PATH`.

## Setup

```bash
ralph init
```

`ralph init` creates these files (existing files are skipped, not overwritten):

- `.ralph/config.yml`
- `.ralph/prompt.md`
- `.ralph/prd.json`
- `.ralph/progress.md`

## Quick start

1. Update `.ralph/prd.json` (`branchName` and stories for your project).
2. Adjust `.ralph/config.yml` `agent.command` for your environment.
3. Check the execution plan with dry-run.

```bash
ralph run --dry-run
```

4. Run for real.

```bash
ralph run
```

Minimal `prd.json` example:

```json
{
  "project": "your-project",
  "plan": "docs/plans/2026-01-01-your-plan.md",
  "branchName": "feature/task-001",
  "stories": [
    {
      "id": "TASK-001",
      "passes": false,
      "deps": []
    }
  ]
}
```

## config.yml

Minimal config generated by `ralph init`:

```yaml
# yaml-language-server: $schema=https://raw.githubusercontent.com/shuymn/ralph/main/schemas/config.schema.json
version: "1"

agent:
  command: "claude -p --dangerously-skip-permissions"

git:
  commit: split
  fallback_message: "feat: implement task (auto-commit)"
  fallback_no_gpg_sign: true

phases:
  pre:
    steps: []
  post:
    steps:
      - name: auto_commit
        uses: auto_commit
        if: changed()
        on_fail: stop_loop
```

Default values (when omitted):

- `agent.max_iterations`: `60`
- `agent.sleep_seconds`: `5`
- `completion.strategy`: `tail_match`
- `completion.signal`: `<promise>COMPLETE</promise>`
- `completion.tail_lines`: `20`
- `git.commit`: `split`
- `git.fallback_message`: `feat: implement task (auto-commit)`
- `git.fallback_no_gpg_sign`: `false`
- `step.if`: `success()`
- `step.on_fail`: `stop_loop`

Step constraints:

- `name` is required.
- Exactly one of `run` or `uses` must be set.
- `uses` currently supports only `auto_commit`.
- `on_fail` must be `continue` or `stop_loop`.

Functions available in `if` expressions:

- `always()`
- `success()`
- `failure()`
- `changed()`

Operators: `!`, `&&`, `||`, `(`, `)` (with `true` / `false` literals).

## auto_commit

`git.commit` modes:

- `split`: split changes into up to 2 commits (`.ralph/` and non-`.ralph/`)
- `together`: commit all changes in 1 commit

Commit message resolution:

- Use `.ralph/.commit-msg` if it exists and is not blank.
- Otherwise use `git.fallback_message`.
- If `git.fallback_no_gpg_sign` is `true` and commit fails due to GPG signing,
  retry once with `git commit --no-gpg-sign`.

## Exit codes

- `0`: success (completed)
- `1`: command failure (general `init`/`run` failure)
- `2`: usage error
- `20`: stopped by `on_fail: stop_loop`
- `21`: completion signal mismatch
- `22`: validation/runtime error
- `23`: `max_iterations` reached

## Development commands

- `task build`: build binary
- `task run`: build and run locally
- `task schema`: regenerate `schemas/config.schema.json`
- `task schema:check`: check schema drift
- `task fmt`: format
- `task lint`: run linters
- `task test`: `go test -race -shuffle=on -count=10 ./...`
- `task check`: `schema:check -> lint -> build -> test`
